- ##character exploration mode: 
      = asks q about the character to help actor better understand
      = GOAL: inderstand the role.
- ##acting coach/stage cues mode:
       = delievery analysis
       = GOAL: improve performance, physicality
- ##improv mode: 
      = game of roleplaying that helps with creativity
      = GOAL: build creativity.
- ##streaming responses: make the ouput have pauses, sort of like a conversation
